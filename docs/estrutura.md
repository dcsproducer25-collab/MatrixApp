# Estrutura do Projeto - MatrixApp

## 📁 Pastas principais
- `app/`: telas e navegação
- `assets/images/`: imagens e ícones
- `docs/`: documentação do projeto

## 📄 Arquivos principais
- `index.tsx`: redirecionamento inicial
- `_layout.tsx`: estrutura de navegação com Drawer
- `login.tsx`: tela de autenticação
- `home.tsx`, `vendas.tsx`, `estoque.tsx`, `relatorios.tsx`: telas funcionais
